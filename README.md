# Minecraft_moded

Модовая сборка Minecraft (Java Edition) для игры с друзьями по сети.

- Варианты хостинга сервера: [docs/hosting.md](docs/hosting.md)
- Заметки для Claude Code: [CLAUDE.md](CLAUDE.md)

## Claude Code
Проект подключает маркетплейс плагинов `rehan-remade/universal-modder` и плагин
`universal-modder` через `.claude/settings.json` — при открытии репозитория в Claude Code
он будет предложен к установке автоматически. Вручную:

```
/plugin marketplace add rehan-remade/universal-modder
/plugin install universal-modder@universal-modder
```
