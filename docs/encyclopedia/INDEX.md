# Справочник-энциклопедия сборки

Справочник по модам сборки **Minecraft 1.20.1 + Forge 47.4.26**: карточка каждого мода (версия, сторона, что делает, ссылки) и разделы «Как играть», «Предметы/блоки», «Мобы» и др. Карточки сгенерированы `scripts/encyclopedia/build.py`; остальное пишется вручную ([как редактировать](README-authoring.md)). Статус: **этап 1 — каркас и карточки**; разделы «Как играть» и т. п. пока пусты.
