## Aether Addon: Emissivity

<!-- auto:start card:aether-emissivity -->
<a id="aether-emissivity"></a>
- **Версия:** 1.20.1-1.0.0-neoforge · **Сторона:** client · **Источник:** [Modrinth](https://modrinth.com/mod/aether-emissivity)
- **Что это:** Аддон к The Aether: добавляет свечение (эмиссивные слои) ряду текстур. _(источник: docs сборки)_
- **В сборке:** клиент
<!-- auto:end card:aether-emissivity -->

### Что даёт игроку

Только клиентский аддон к The Aether: добавляет светящиеся (эмиссивные) слои текстурам Эфира — амброзиевая руда и факел, алтарь Солнца, камни стражей и ангельский камень, а по настройкам клиентского конфига — фениксову броню, ботинки стража, Щит отталкивания (`emissive_phoenix_armor`, `emissive_sentry_boots`, `emissive_shield_of_repulsion`). Геймплей не меняет. Нужен только игроку (side `client`); наших конфигов в `pack/config` нет.

## Aether Addon: Treasure Reforging

<!-- auto:start card:aether-treasure-reforging -->
<a id="aether-treasure-reforging"></a>
- **Версия:** 1.20.1-1.0.1-neoforge · **Сторона:** both · **Источник:** [Modrinth](https://modrinth.com/mod/aether-treasure-reforging)
- **Что это:** Аддон к The Aether: сокровищное снаряжение из данжей переплавляется в сырьё, из которого новыми шаблонами кузнеца куётся другое сокровищное снаряжение. _(источник: docs сборки)_
<!-- auto:end card:aether-treasure-reforging -->

### Что даёт игроку

Аддон к The Aether (Treasure Reforging): снаряжение из сокровищниц подземелий можно переплавить в сырьё — **Pyral** (`pyral_ingot`, `pyral_shard`, `pyral_block`), **Valkyrum** (`valkyrum_ingot`, `valkyrum_block`), **Neptune Mesh** (`neptune_mesh`) — и «перековать» через кузницу с шаблонами в другое снаряжение: улучшения `phoenix_upgrade` (к броне гравитита; ингредиент — Pyral), `valkyrie_upgrade` (к снаряжению гравитита; Valkyrum), `neptune_upgrade` (к броне зенита; Neptune Mesh). Достижений — 32.
**Особенность сборки**: три рецепта крафта самих шаблонов (`valkyrie`/`phoenix`/`neptune_upgrade_smithing_template`) отключены нашим KubeJS (`forge:false`, ингредиенты из отсутствующих модов; [compat.md](../compat.md), [jei.md](../jei.md)) — остальная механика мода работает.

## Aether Villages

<!-- auto:end card:aether-villages -->

### Данжи/структуры (/locate)

Аддон к The Aether (Aureljz, DiamondTown): «величественные храмы и деревни в небесах Эфира». Одна структура — `aether_villages:olympic_citadel` (Olympic Citadel), расстановка `random_spread`: шаг 70, разделение 65 чанков. Искать: `/locate structure aether_villages:olympic_citadel` (в Эфире). Лут и теги — свои (`aether_villages:collections/ancient_aether_biomes` убирается нашим KubeJS из недостающих ссылок, [compat.md](../compat.md)). Крупные шаблоны структуры тяжелы для генерации (`olympic_citadel_main_0` — 1,4 млн, [compat.md](../compat.md)).

Главный шаблон `olympic_citadel_main_0` огромный (≈1,4 млн блоков, почти весь — воздух): для него в `mm-compat` стоит исправление копирования шаблонов при генерации (иначе мусор в куче на каждый чанк структуры), см. [compat.md](../compat.md).

## Alex's Caves

<!-- auto:start card:alexs-caves -->
<a id="alexs-caves"></a>
- **Версия:** 2.0.2 · **Сторона:** both · **Источник:** [Modrinth](https://modrinth.com/mod/alexs-caves)
- **Что это:** Шесть редких пещерных биомов под поверхностью Верхнего мира, со своими мобами и предметами. _(источник: docs сборки)_
- **В наших docs:** [compat.md](../compat.md) (11), [enchanting-table.md](../enchanting-table.md) (5), [dedup.md](../dedup.md) (4), [ntm.md](../ntm.md) (4), [expensive-crafts.md](../expensive-crafts.md) (3), [friends.md](../friends.md) (3)
<!-- auto:end card:alexs-caves -->

### Как играть

Мод Alex's Caves (Alexthe668) — не новое измерение, а шесть редких пещерных биомов, спрятанных глубоко под Верхним миром:
1. Биомы (`alexscaves:*`): **Magnetic Caves** (`magnetic_caves`), **Primordial Caves** (`primordial_caves`), **Toxic Caves** (`toxic_caves`), **Abyssal Chasm** (`abyssal_chasm`), **Forlorn Hollows** (`forlorn_hollows`), **Candy Cavity** (`candy_cavity`). Поиск: `/locate biome alexscaves:toxic_caves` и т. п.
2. Справочник — **Cave Compendium** (`cave_book`, «By Dr. Prof. Alexander Caverns, PhD»; разделы General, Resources, Inhabitants, Utilities, Secrets).
3. Находить биомы помогает **Cave Biome Map** (`cave_map`): её делают в **Spelunkery Table** (`spelunkery_table`) из **Cave Tablet** (`cave_tablet`): табличка кладётся в слот и «исследуется» (после старта не вынуть; может треснуть/рассыпаться).
4. Прогресс по каждому биому: добыть руду/материал (неодим, уран, полимер и пр.), сделать снаряжение и приручить/победить жителей. Основной документ сборки — [compat.md](../compat.md) (уран не объединяется Almost Unified, у мода своя радиация); боссы — [bosses.md](../bosses.md#alexscaves); руды ОреСпавна — [orespawn.md](../orespawn.md).
5. Связка с Create — «Create: Alex's Caves Compat», с едой — Alex's Caves Delight (карточки ниже/на «Еде»).

5. Наш KubeJS отключает рецепт `ancient_aether:ancient_rune` (его ингредиент из отсутствующего мода) — см. [compat.md](../compat.md); босс — в [bosses.md](../bosses.md#ancient_aether).

Мод Blue Skies (Modding Legacy) добавляет два измерения: `blue_skies:everbright` («Вечный день», холодный, снег, духи) и `blue_skies:everdawn` («Вечный рассвет», жаркий и влажный, насекомые и рептилии). Из журнала мода:
1. Постройте рамку-портал из **бирюзовых каменных кирпичей** (`turquoise_stonebrick`) — в Everbright — или **лунных** (`lunar_stonebrick`) — в Everdawn.
2. Зажгите её **зажигалкой усердия** (`zeal_lighter`) — внутри появится `everbright_portal` / `everdawn_portal`.
3. Полезно взять **Синий журнал** (`blue_journal`, «An adventurer's guide — The Gatekeeper»): справочник на ~80 разделов (мобы, руды, подземелья, рецепты). Его даёт Хранитель (`gatekeeper`) из домиков `gatekeeper_house_*`.
4. Подземелья открываются «ключами этажей» и закрываются **краеугольными камнями** (keystone): каждый этаж даёт ключ, на верхнем нужно вставить 4 ключа. Боссы и награды — в [bosses.md](../bosses.md#blue_skies).
5. Совместимость: Create Blue Skies Compat, Blue Skies Tweaks, Blue Skies Gravestones Compat, Farmer's Cutting: Blue Skies — отдельные карточки/строки в [compat.md](../compat.md).

4. Полёт: **Душевые надкрылья** (`soul_elytra`) с рывком (клавиша «Boost Soul Elytra»).
5. Босс Otherside — **Сталкер** (`stalker`); подробности — [bosses.md](../bosses.md#deeperdarker). Совместимость и допы: «Deeper and Darker: Spellbooks» (Iron's Spells), «Deeper and Darker → Cataclysm», «Dungeons and Villages: Deeper and Darker» (см. карточки ниже и [compat.md](../compat.md)).

Мод Dimensional Dungeons (автор Catastrophe573) добавляет «измерения подземелий» (`dimdungeons:dungeon_dimension`) и личное строительное измерение (`dimdungeons:build_dimension`). Попасть можно только порталом с ключом:
1. **Портал**: нужны 3 **позолоченных портальных блока** (`block_gilded_portal` — чиселированный каменный кирпич в кольце из 8 золотых слитков) и **портальная замочная скважина** (`block_portal_keyhole` — позолоченный блок + Око Эндера + сундук-ловушка). Рамка — из каменных кирпичей, 4 блока в высоту и 3 в ширину (2 воздуха внутри), верхний центр заменяется замочной скважиной; по бокам на расстоянии 1 блока ставятся «шпили» (3 блока высотой, сверху позолоченный блок); на верх рамки — два `block_portal_crown`; на шпили вешаются белые/пурпурные флаги с нужным узором (см. сообщения об ошибках при неверной постройке).
2. **Ключ**: Blank Portal Key (`item_portal_key`) крафтится из бирки и огненного стержня. Чтобы его **активировать**, зайдите в крепость и используйте ключ на **верхней стороне рамки портала Края** — ключ получит уникальное имя и всегда ведёт в одно и то же подземелье. Ключ вставляют в замочную скважину портала.
3. В подземелье (обычные и «продвинутые» — вдвое больше) — ловушки, загадки, сундуки. «Продвинутый» ключ (`item_portal_key_advanced`) находят внутри. Книгу-гайд мод выдаёт через Patchouli: чиселированный кирпич + книга; в сборке книга русифицирована своим файлом `pack/kubejs/data/dimdungeons/patchouli_books/guide_book/book.json`.
4. Полезен **Homeward Pearl** (`item_homeward_pearl`: ключ + жемчуг Эндера + бутылочка опыта) и жемчуга Эндера для ловушек.
5. Личное измерение: **Personal Dimension Key** (`item_build_key`, заготовка — 6 жемчугов Эндера, Homeward Pearl, осколок эха, блок травы); доступ можно закрыть списками гостей (бумага, книга, белый/чёрный краситель, точило на портале — `security.dimdungeons.*`).

- **Что это:** Генерирует заброшенные города (улицы, шоссе, здания с подвалами, метро, спавнерами и сундуками) прямо в обычном Overworld; в сборке включён редкий профиль rarecities (≈6 % городских чанков), действует для нового мира. _(источник: docs сборки)_
- **В сборке:** The Lost Cities (McJty, MIT): города в обычном Overworld; профиль — pack/defaultconfigs/lostcities-server.toml
- **В наших docs:** [compat.md](../compat.md) (18), [lost-cities.md](../lost-cities.md) (17), [roadmap.md](../roadmap.md) (11), [vampirism.md](../vampirism.md) (9), [performance.md](../performance.md) (8), [friends.md](../friends.md) (3)

### Как играть

Это не отдельное измерение и не тип мира: города генерируются **в обычном Overworld** (биом-модификатор `lostcities:lostcities`, стадия `raw_generation`, биомы `#minecraft:is_overworld`). Рядом с городами обычный ландшафт и все остальные структурные моды сборки. Подробности выбора и замеров — [lost-cities.md](../lost-cities.md).

- **Профиль** читается из серверного конфига **при создании мира**; у нас `rarecities` ([Конфиги](#the-lost-cities)). На уже созданном мире профиль не меняют: новые чанки дадут резкую границу. Хотите города — новый мир (или другой `level-name`).
- **Частота** (замер сетки ±1500 блоков, seed 12345): `default` — 37 % «городских» чанков, `rarecities` — 5,8 %. Города редкие, среди обычных биомов.
- **Что внутри города:** улицы (в т. ч. широкие), парки и фонтаны, здания с подвалами, мосты, шоссе между городами, метро/рельсовые подземелья, одиночные постройки вне города (см. ниже). Здания частично разрушены (рубль `rubble`, паутина, цепи); в зданиях стоят спавнеры и сундуки.
- **Жить и ехать/лететь без OOM:** в сборке уже стоят два исправления в `mm-compat` (утечка `BuildingInfo` и копирование огромных шаблонов структур); память и правила — в разделе «Конфиги». Тяжёлые профили (`tallbuildings`, `largecities`, `onlycities`) не включать.
- Мод поставлен как `both`: сервер обязателен; клиенту нужен для экрана выбора профиля в одиночной игре (экран захардкожен по-английски).

### Мобы

Отдельных мобов мод не добавляет. В палитре зданий стоят ванильные спавнеры (`minecraft:spawner`) двух классов:
- `easymobs` (лёгкие): `minecraft:zombie`, `minecraft:skeleton`, `minecraft:spider`;
- `hardmobs` (тяжёлые): `minecraft:blaze`, `minecraft:witch`.

Спавнеры находятся в зданиях и подвалах; зачищайте перед обустройством. Мобов других модов (Lycanites, Mowzie's и т. д.) город не спавнит, но они гуляют по окрестностям как обычно.

### События

Своих событий нет. Для безопасных зон можно использовать профиль `safe`, но в сборке он не включён.

### Данжи/структуры (/locate)

Города — не `structure` Minecraft, поэтому `/locate structure` их не находит. Искать так:
- `/lostcities locate <здание>` — координаты ближайшего здания по имени (подсказка по `buildings`/`multibuildings`);
- `/lostcities map` — текстовая карта окрестностей (город, улица, шоссе, рельсы и т. д.);
- `/lostcities stats` — статистика генерации; `/lostcities debug` — отладочная информация о чанке (тип: `NORMAL_TERRAIN`, `BUILDING`, `MULTI_BUILDING`, `PLANNED_ROAD`…).

Подземное `rail_dungeon1/2` ищется по городу: рельсовые подземелья идут под городами и шоссе.
Структуры ванили (`mansion`, `pyramid`, `igloo`, `swamp_hut`, `outpost`) Lost Cities обходит сам (`avoidStructures`); для структур прочих модов (Cataclysm и др.) список не расширяли — не требовалось ([lost-cities.md](../lost-cities.md)).

#### Наши исправления под нагрузку (`mods-src/mm-compat`)
- `LostCitiesNeighborMixin` (mm-compat 0.5.5): `BuildingInfo.getXmin/getXmax/getZmin/getZmax` запоминали соседа в полях; вся сетка сгенерированных городов оставалась в куче (47 тыс. → 705 тыс. объектов за 12 мин полёта, old gen 6,1/6,1 ГБ, `OutOfMemoryError`). Теперь сосед берётся из кэша каждый раз. Действует и на уже созданных мирах ([compat.md](../compat.md), причина — запись H-002 в [issue-history.md](../issue-history.md)).
- `StructureTemplatePlaceMixin` (там же): огромные шаблоны структур других модов (кубы до 128³) копировались целиком для каждого чанка; теперь шаблонам от 65 536 блоков передаются только блоки чанка по X/Z. Это не Lost Cities, но тот же сценарий полёта над новыми чанками.
- Параметр `cacheCleanupSeconds` (по умолчанию 300) не лечит утечку — замером на 60 с рост тот же; без миксина менять его бесполезно.

**Как ехать/лететь без OOM:** оставляйте `rarecities`; не включайте WorldEdit у клиента (≈ 2,7 ГБ постоянно); при лагах при подгрузке — `/spark profiler` ([performance.md](../performance.md)). Генерация одного городского чанка из скрипта на облачной ВМ ≈ 2,8 с (холодный старт), на обычном ноутбуке ощутимо меньше.

### Как играть

1. Найдите небольшой водоём (источник воды) и обсадите его по краю любыми растениями (трава, папоротник, цветы, грибы, лоза, сахарный тростник и т. п. — тег `twilightforest:portal/decoration`).
2. Бросьте в воду **алмаз** (предмет из тега `forge:gems/diamond`, он же `twilightforest:portal/activator`): вода превратится в портал.

4. Подсказка по ходу игры — книга достижений («Twilight Forest»), её корень: «Enter the mysterious, magical woodlands».
5. Для еды, броской мебели и декора есть аддоны: Twilight Delight, Twilight Forest: The Lost Blocks, Twilight Forest Bosses Resurrection (см. карточки ниже). Боссы мода и их HP — в [bosses.md](../bosses.md); совместимость с остальной сборкой — [compat.md](../compat.md).

Измерение `undergarden:undergarden` («Подземный сад») — тёмный мир с густой растительностью, без неба.
1. Постройте рамку портала (как у Незера) из блоков тега `undergarden:portal_frame_blocks`: каменные или глубинносланцевые кирпичи (`stone_bricks`, `mossy_stone_bricks`, `deepslate_bricks`, `deepslate_tiles`, `polished_deepslate`), а также `undergarden:depthrock_bricks`, `depthrock_tiles`, `polished_depthrock`, `shiverstone_bricks`.
2. Сделайте **Катализатор** (`undergarden:catalyst`, достижение «One Ticket Please»): золото и железо вокруг алмаза (`GIG / IDI / GIG`, где G — слиток золота, I — железа, D — алмаз) — и активируйте им рамку; появляется `undergarden_portal`.
3. Прогресс по металлам (руды в `depthrock`/`shiverstone`): клоггрум (`cloggrum`), froststeel, ригалий (`regalium`), утериум (`utherium`), затем «забытый металл» (`forgotten`); улучшение до забытого — через шаблон кузницы `forgotten_upgrade`.
4. Оружие дальнего боя — **Рогатка** (`slingshot`); по достижениям ею стреляют камешками (`depthrock_pebble`), шариками Scintling Goo (`goo_ball`), Гронглетами и гнилыми ягодами блистерберри.
5. Босс — **Забытый страж** (`forgotten_guardian`, достижение «Decommissioned»). Боссы и HP — [bosses.md](../bosses.md#undergarden); Undergarden Delight — карточка в странице «Еда и фермерство».
