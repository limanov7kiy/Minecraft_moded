# Как редактировать справочник

Справочник — `docs/encyclopedia/`, оглавление — [INDEX.md](INDEX.md). Карточки модов генерирует
`scripts/encyclopedia/build.py`, поэтому часть текста нельзя править руками: её перезапишет следующий запуск.

## Что генерируется, что пишется вручную
- **Между маркерами `<!-- auto:start ... -->` и `<!-- auto:end ... -->` — только генератор.** Это блок `toc`
  (список модов страницы), блок `card:<ключ>` (версия, сторона, описание, ссылки, упоминания в docs)
  и блоки `cats`/`articles`/`alpha` в INDEX.md. Руками тут ничего не пишем — исправляйте источник (см. ниже).
- **Всё вне маркеров — ваше.** Под каждой карточкой лежат заготовки подразделов «Как играть», «Предметы/блоки»,
  «Мобы», «Эффекты», «События», «Данжи/структуры (/locate)», «Чары», «Команды/гамерулы», «Конфиги»
  (в каждой стоит строка «Пока пусто…»): заменяйте её текстом, ненужные подразделы можно удалять.
  Заголовок карточки (`## Название`) тоже ручной — его можно переименовать, ключ карточки в маркере не меняется.
- Обзор категории — раздел «Общее по категории» на каждой странице (перед `<!-- cards:start -->`).
- Своя статья — отдельный файл (например `arknights/mind-storm.md`); ссылку на неё добавьте в `extra` нужной категории
  в `scripts/encyclopedia/categories.toml` — она попадёт и в INDEX, и на страницу категории.

## Источники данных карточки
| Что в карточке | Откуда |
|---|---|
| имя, сторона, ссылка на Modrinth/CurseForge | `pack/mods/*.pw.toml`, `pack/resourcepacks/*.pw.toml` |
| версия, описание (англ.) у модов с Modrinth | `scripts/encyclopedia/meta-cache.json` (обновляется `fetch_meta.py`) |
| имя, версия, описание наших и «ручных» jar | `META-INF/mods.toml` внутри `pack/mods/*.jar` |
| «В сборке» | заметка из `pack/modlist.txt` |
| «В наших docs» | поиск названия по `docs/**/*.md` (в скобках — число упоминаний) |
| категория мода | `scripts/encyclopedia/categories.toml` |

## Команды
```
python3 -I scripts/encyclopedia/fetch_meta.py   # изредка: подтянуть описания/версии с Modrinth (нужна сеть)
python3 -I scripts/encyclopedia/build.py        # пересоздать авто-блоки; печатает счётчик и непокрытые моды
python3 -I scripts/encyclopedia/build.py --check # ничего не писать; код 1, если файлы устарели или есть проблемы
```
Скрипт завершается с ошибкой, если мод из `pack/modlist.txt` не получил карточку или у мода нет категории.

## Добавить или перенести мод
1. Мод попал в сборку (`pack/modlist.txt`, `pack/mods/`) → запустите `fetch_meta.py` (для Modrinth-модов) и впишите ключ
   (имя `.pw.toml` без суффикса; для jar — имя файла до версии, скрипт выведет его в «БЕЗ КАТЕГОРИИ») в `[members]`
   файла `categories.toml`. Затем `build.py` — карточка появится в конце страницы категории (внутри `cards:start/end`).
2. Перенос между категориями: поменяйте `categories.toml` и перенесите блок карточки (заголовок, маркеры, подразделы)
   на другую страницу руками. Пока карточка лежит в старом месте, скрипт её там и обновляет.
3. Мод удалён из сборки → карточку уберите руками; скрипт предупредит «карточка есть, мода в сборке нет».
4. Нет описания → допишите его в `[descriptions]` файла `categories.toml`.

Репозиторий публичный: не вставляйте в справочник секреты, логи с личными данными и ники игроков.
