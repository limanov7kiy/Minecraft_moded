# Чистый сброс сервера после тестирования (поток 67, 2026-10-26)

Просьба владельца: когда тестирование закончится — **новый мир и обнуление всех достижений, исследований и прогресса**.
**Сам сброс делается ТОЛЬКО по прямой команде владельца.** Этот документ — опись и порядок действий; ничего автоматического нет.
Решения по спорным пунктам — вопросы владельцу в конце (В##).

## 1. Где хранится прогресс
Опись сделана по тестовому серверу (`scripts/test-server.sh`) и по сохранению одиночного мира после входа настоящего игрока (`scripts/test-client.sh`).
Показать опись на любом сервере (ничего не удаляет): `scripts/reset-inventory.sh <папка сервера>`.

### Внутри папки мира (`world/` — имя из `level-name` в `server.properties`) — удаляется целиком
| Что | Где | Что там |
|---|---|---|
| Игроки | `world/playerdata/<UUID>.dat` | инвентарь, эндер-сундук, опыт, эффекты, позиция; **все «способности» модов** (ForgeCaps): раса и силы Origins / Arknights Races, магия (Ars Nouveau, Iron's Spells, Mana and Artifice, Ars Magica, Wizardry, Mahou Tsukai), изученные чары ESO (`esodata`), Curios, жажда/температура/здоровье LSO, радиация Mekanism, Aether, Twilight Forest, Lycanites и др. |
| Достижения | `world/advancements/<UUID>.json` | все достижения, в том числе модовые |
| Статистика | `world/stats/<UUID>.json` | статистика игрока |
| Общие данные мира | `world/data/*.dat` | рюкзаки Sophisticated Backpacks, точки Waystones, навыки Puffish Skills, сезоны (Serene Seasons, SSP), корабли Valkyrien Skies, хроники/переменные Contingency Contract, мегаструктуры Torches Become Sunlight, Lost Cities, Weather2, рейды, табло (`scoreboard.dat`), LOD Distant Horizons (`DistantHorizons.sqlite`) и др. |
| Карта всех измерений | `world/region`, `world/DIM-1`, `world/DIM1`, `world/dimensions/<мод>/<измерение>` (Aether, Twilight Forest, Ad Astra, Lost Cities, Torches Become Sunlight и т.д.), `entities`, `poi` | постройки, сундуки, мобы |
| Звуки AudioPlayer | `world/audio_player_data/` | привязки загруженных звуков к пластинкам/рогам |
| Данные KubeJS | `world/kubejs_persistent_data.nbt` | сохранённые переменные скриптов |
| Серверные конфиги мира | `world/serverconfig/` | **пересоздаются** из `defaultconfigs/` сборки при создании нового мира (проверено: `lostcities-server.toml` из сборки на месте) |

### Вне папки мира
| Что | Где | При сбросе |
|---|---|---|
| Кэш карт измерения Torches Become Sunlight | `data/tbs/` (в корне сервера, ~6 МБ) | удалить — пересоздаётся при запуске (проверено) |
| Задачи прегенерации Chunky | `config/chunky/tasks/` | удалить (задача старого мира) |
| Позиции возврата Sol's AuthLogin | `solsauthlogin/return_positions.json` (+ `.bak`) | удалить (координаты старого мира) |
| **Регистрации Sol's AuthLogin** (хэши паролей) | `solsauthlogin/credentials.json` (+ `.bak`) | **вопрос владельцу**, по умолчанию сохранить |
| Постоянные группы голосового чата | `config/enhancedgroups/persistent-groups.json`, `auto-join-groups.json` | вопрос владельцу, по умолчанию сохранить (не прогресс) |
| Загруженные звуки AudioPlayer | `audioplayer_uploads/` | вопрос владельцу, по умолчанию сохранить |
| Операторы, белый список, баны, кэш ников | `ops.json`, `whitelist.json`, `banned-*.json`, `usercache.json` | сохранить |
| Конфиги, моды, KubeJS сборки | `config/`, `mods/`, `kubejs/`, `defaultconfigs/` | не трогать (обновляются сборкой) |
| Кэши | `modernfix/`, `local/`, `logs/`, `crash-reports/` | можно не трогать |

Не найдено в сборке: FTB Quests / FTB Teams (нет), JourneyMap (нет — стоят Xaero), отдельных баз прогресса вне мира у модов магии и рас нет — всё в `playerdata`.

## 2. Порядок сброса на Millida (по команде владельца)
1. **Предупредить игроков**, дождаться, пока все выйдут.
2. **Бэкап.** В панели Millida — «Бэкапы → создать» (ручные хранятся 30 дней, `docs/hosting.md`). Дополнительно (по желанию) скачать по SFTP архив:
   `world/`, `data/tbs/`, `solsauthlogin/`, `config/enhancedgroups/`, `audioplayer_uploads/` — на тестовом сервере архив этого списка занял ~35 МБ после часа тестов;
   на живом сервере после прегенерации — гигабайты (≈ 50 КБ на чанк).
3. **Остановить сервер** в панели (`stop` в консоли; дождаться «Остановлен»).
4. **Удалить** (через файловый менеджер панели или SFTP):
   - `world/` (вся папка мира);
   - `data/tbs/`;
   - `config/chunky/tasks/`;
   - `solsauthlogin/return_positions.json` и `solsauthlogin/return_positions.json.bak`;
   - по ответам владельца (В##): `solsauthlogin/credentials.json*`, `config/enhancedgroups/*.json`, `audioplayer_uploads/`.
5. **Новый seed.** В `server.properties` (или настройках панели): `level-seed=` — пусто для случайного мира, либо конкретное число.
   Остальные строки не трогать (`online-mode=false`, `max-tick-time=-1`, `sync-chunk-writes=false`, порты).
6. **Запустить** сервер. Первый запуск нового мира — около минуты до `Done`.
7. **Проверить:** зайти самому — новый мир, нет инвентаря и достижений, при входе снова выбор расы (Origins); `/seed` показывает новый seed;
   в логе нет `crash-reports`. Опись после сброса: `scripts/reset-inventory.sh` — `world` новый и маленький.
8. **Прегенерация** — `docs/hosting.md`, «Прегенерация мира после первого запуска (Chunky)», пока никто не играет.
9. Сообщить игрокам, что клиентам нужно почистить (ниже).

Проверено на тестовом сервере (2026-10-26): архив → удаление списка шага 4 → `level-seed=` пусто → запуск: `SERVER OK`, мир создан заново, `data/tbs/` пересоздан,
`world/serverconfig/` заполнен из `defaultconfigs/`, `world/playerdata` пуст.

## 3. Что почистить у игроков (клиент, Prism → экземпляр → Папка)
- **Карты Xaero** (Minimap и World Map): папки сервера в `xaero/minimap/` и `xaero/world-map/` (имя — адрес сервера, например `Multiplayer_<адрес>`).
  Без очистки старые метки и исследованная карта наложатся на новый мир. Удалять при закрытой игре; одиночные миры (папки с их именами) не трогать.
  Резервные копии меток Xaero (`XaeroWaypoints_BACKUP…`) — можно удалить.
- **Distant Horizons**: LOD сервера хранятся в `Distant_Horizons_server_data/<сервер>/` — удалить папку этого сервера, иначе дальние холмы будут от старого мира
  (путь — по документации DH; в облаке на сетевом сервере не проверялся).
- Больше ничего: инвентарь, расы, магия, достижения — на сервере. Модели YSM, конфиги и `options.txt` сбрасывать не нужно.

## 4. Вопросы владельцу (В##)
1. **Регистрации входа (Sol's AuthLogin):** а) **сохранить** — друзья входят со старыми паролями (удаляются только позиции возврата); б) сбросить — все регистрируются заново (`/register`).
   **Рекомендация: а** — это не игровой прогресс, а безопасность ников; сброс только добавит хлопот.
2. **Старый мир:** а) **хранить архив** — ручной бэкап Millida (30 дней) + архив на ПК владельца; б) удалить без архива.
   **Рекомендация: а** — архив недорогой, а вернуть постройку/вещь после «чистого» старта иначе невозможно.
3. **Seed нового мира:** а) **случайный** (`level-seed=` пусто); б) конкретный (если хотите заранее посмотреть место спавна). **Рекомендация: а.**
4. **Голосовые группы и загруженные звуки** (Enhanced Groups, AudioPlayer): а) **сохранить**; б) сбросить вместе с миром. **Рекомендация: а** — не прогресс.
5. **Операторы, белый список, баны:** а) **сохранить**; б) сбросить. **Рекомендация: а.**
