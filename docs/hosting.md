# Где поднимать сервер

Два сценария: сервер на ПК друга (бесплатно, но работает, только пока ПК включён)
или платный хостинг (24/7).

## Вариант A: ПК друга

Сначала проверить, есть ли у друга «белый» (публичный) IP: сравнить IP в настройках роутера
(WAN) с тем, что показывает 2ip.ru. Совпадают — IP белый.

| Способ | Что ставить игрокам | Плюсы | Минусы |
|---|---|---|---|
| **Проброс порта 25565** (если IP белый) | ничего | минимальный пинг, без посредников | нужен доступ к роутеру; IP может меняться (решается DDNS) |
| **playit.gg** | ничего | работает за NAT/CGNAT, постоянный адрес, бесплатный тариф | трафик идёт через их сервер — пинг выше; на бесплатном тарифе ближайший регион может быть далеко |
| **Tailscale / ZeroTier** (виртуальная LAN) | клиент VPN у каждого | обычно прямое P2P-соединение — пинг ниже, чем у туннеля; закрыт от посторонних | каждый игрок ставит программу и входит в сеть |
| **Radmin VPN** | клиент у каждого | просто, популярен в СНГ | только Windows, иногда нестабилен |
| **e4mc** (мод) | ничего | «открыть для сети» прямо из одиночного мира | хост должен сам сидеть в игре; адрес временный — для долгой сборки не подходит |

**Рекомендация:** если IP белый — проброс порта. Если нет — **playit.gg** для простоты
(друзьям ничего ставить не нужно); если пинг через playit окажется плохим — **Tailscale**.

Требования к ПК друга для модовой сборки: 6–8 ГБ RAM под сервер (средняя сборка на 50–150 модов),
процессор с хорошей однопоточной производительностью, SSD, проводное подключение.

## Голосовой чат: UDP-порт 24454

Simple Voice Chat ходит **отдельным UDP-портом 24454** (не через порт игры 25565, который TCP).
Если игра подключается, а в голосовом чате значок «нет соединения» (перечёркнутый динамик/наушники) —
не открыт именно этот порт. Настройки сервера: `pack/config/voicechat/voicechat-server.properties`
(`port` — какой порт слушать, `voice_host` — какой адрес сообщить клиентам; пусто = тот же, что у игры).

| Способ подключения | Что сделать для голоса |
|---|---|
| **Проброс портов** (белый IP) | в роутере, кроме `25565/TCP`, пробросить **`24454/UDP`** на тот же ПК; в брандмауэре Windows разрешить входящий UDP 24454 для Java (или правилом на порт). `voice_host` не трогать. |
| **playit.gg** | Добавить в агенте **второй туннель типа UDP** на локальный `127.0.0.1:24454` (первый — Minecraft Java, TCP 25565). playit выдаст адрес вида `xxx.ply.gg:12345` или `147.185.221.x:12345` — вписать его в `voice_host=xxx.ply.gg:12345` и перезапустить сервер. Клиенты ничего не настраивают: адрес приходит от сервера. Бесплатный тариф позволяет несколько туннелей, UDP в том числе. |
| **Tailscale / ZeroTier / Radmin VPN** | Ничего: в виртуальной сети все порты, включая UDP, доступны напрямую. Друзья подключаются к адресу хоста в сети (`100.x.y.z` у Tailscale), голос идёт туда же. Брандмауэр Windows всё равно должен пропускать Java (обычно спрашивает при первом запуске — разрешить для частных сетей). |
| **e4mc** | Голос не работает: e4mc туннелирует только TCP игры. |
| **Платный хостинг** | В панели хостинга выделить дополнительный порт (часто называется «Additional port»/«Allocation») и вписать его в `port=` (и в `voice_host=адрес:порт`, если хостинг за NAT). Если хостинг даёт только один порт — `port=-1` (голос по UDP на том же номере, что игра) и обязательно `enable-query=false` в `server.properties`: query тоже слушает UDP на этом порту, и SVC предупреждает о падении сервера. Узнать у поддержки, проходит ли UDP. |

Проверка: зайти на сервер, нажать **V** — в окне голосового чата не должно быть надписи о недоступности
сервера; в логе сервера строка `Voice chat server started at port 24454`.

## Вариант B: платный хостинг

На что смотреть при выборе тарифа:
- **RAM**: 6–8 ГБ для средней сборки, 10–12 ГБ для тяжёлой (Create, большие тех-моды, много игроков).
- **CPU**: важна однопоточная частота (сервер Minecraft в основном однопоточный) — Ryzen 7000/9000 или
  Intel последних поколений лучше «многоядерных» Xeon старых поколений.
- **Расположение** — ближе к игрокам (пинг).
- **Доступ к файлам** (SFTP/файловый менеджер), выбор версии Java и загрузчика, автобэкапы.
- Возможность поставить свою сборку (zip / server pack), а не только из каталога хостинга.

## Что потребуется от сборки в любом случае
`scripts/export-pack.sh` собирает оба пакета в `dist/` (инструкция для игроков — `docs/friends.md`):
- Серверный пакет `*-server.zip`: только моды со стороной `both` и `server`, конфиги, установщик Forge,
  `start.sh`/`start.bat`. Открыть порты: `25565/TCP` (игра) и `24454/UDP` (голос).
- Клиентский пакет `*.mrpack`: все моды `both` + `client`, импортируется в Prism Launcher / Modrinth App.
