# Где поднимать сервер

Два сценария: сервер на ПК друга (бесплатно, но работает, только пока ПК включён)
или платный хостинг (24/7).

## Сколько ресурсов нужно нашей сборке (замер)
Замер `spark` на тестовом сервере (≈150 модов, 2026-10-10): после запуска и прогрузки участка 400×400 блоков
без игроков — **3,0 ГБ кучи + 0,6 ГБ вне кучи**, TPS 19–20, тик 4–5 мс (95% — 7 мс). Каждый игрок, который
исследует мир, добавляет ориентировочно 0,5–1 ГБ, Create/Valkyrien Skies/Mekanism-базы — ещё больше.

Для **5–8 игроков**: `-Xmx10G` (в серверном пакете так и стоит, `user_jvm_args.txt`), машине — **12 ГБ свободной
памяти** под сервер (на ПК, где одновременно играют, — 24–32 ГБ всего), процессор с высокой однопоточной
частотой (Ryzen 5000/7000, Intel 12-го поколения и новее), SSD. Если TPS падает ниже 18 — `spark profiler`
покажет, какой мод тормозит.

**Рекомендация:** сначала сыграть сессию на ПК самого мощного из друзей (бесплатно, проверим сборку под

(серверный zip из `scripts/export-pack.sh`), какой **процессор** (частота важнее числа ядер).
Цены — по агрегаторам на октябрь 2026, перед оплатой сверить на сайте хостинга.

### Подводные камни (что проверять у любого хостинга)
- **Overselling CPU** и «безлимитный» диск/RAM: после покупки сразу `spark` под нагрузкой; у Millida «выделенные ядра Ryzen 9 7950X» — сверить по `/spark tps`.
- **UDP 24454**: ни на одной странице тарифов нет прямого ответа. Обычно «Network → Create Allocation» в Pterodactyl-панели либо заявка в поддержку. Запасной вариант без доп. порта: `port=-1` в `voicechat-server.properties` + `enable-query=false` (см. выше) — если хостинг пропускает UDP на порт игры.
- **Версия Forge 47.4.26 и Java 17**, **свой стартовый скрипт / свой server jar**: у игровых хостингов обычно выбирается из каталога; спросить, можно ли залить наш `*-server.zip` (1,5 ГБ) и запускать со своими JVM-флагами (`-Xmx10G`).
- **Лимит размера загрузки** через веб-панель — заливать по SFTP; **лимит числа файлов** (229 модов + мир).
- **Правила хостинга про моды / изменённые jar** — на страницах не найдены; юридически сборка остаётся нашим делом (см. «Назначение и лицензии» в `CLAUDE.md`), репозиторий и jar не публиковать.
- **Возврат денег** у Millida на странице не указан — **перед оплатой за год сначала месяц**.

### Вопросы поддержке Millida (и любого другого) до оплаты
1. Можно ли выделить **дополнительный UDP-порт** (24454) для Simple Voice Chat, и бесплатно ли? Пропускается ли UDP на основной порт игры (`port=-1`)?
2. Можно ли залить **свой серверный пакет** (Forge 47.4.26, Java 17, свой `user_jvm_args.txt`, 229 модов, 1,5 ГБ) по SFTP и запускать со своими JVM-флагами `-Xmx10G`?
3. Какой **процессор и политика по overselling**; возврат денег; есть ли расписание перезапуска и консоль; можно ли поменять тариф с 12 на 16 ГБ без потери мира.

### Чек-лист проверки на бесплатном тарифе Millida (решение владельца: сначала проверка, платный не оплачивать)
Регистрация и сервер 2 ГБ без карты; проверяем и записываем результат сюда (ДА/НЕТ + скриншот или цитата поддержки):
1. Выбор ядра: есть ли Forge **1.20.1 / 47.4.26**; выбор **Java 17**; можно ли править `user_jvm_args.txt` / стартовую команду (флаги `-Xmx`).
2. **SFTP**: адрес, порт, логин; заливка своего jar (`*-mmport.jar`) и папок `kubejs/`, `config/`, `defaultconfigs/`, датапаков; лимит размера и числа файлов; можно ли залить весь `*-server.zip` (1,5 ГБ) и распаковать.
3. **UDP 24454**: есть ли в панели «Сеть/Порты/Allocation»; если нет — запрос в поддержку на доп. UDP-порт (цена?) и проверка `port=-1`; проверка снаружи (клиент с Simple Voice Chat, `Voice chat server started at port …` в логе).
4. Консоль и команды (`/spark`, `/op`), перезапуск по расписанию, бэкапы (сколько, как восстановить), смена тарифа 12 → 16 ГБ без потери мира.
5. Условия: **возврат денег**, правила про загрузку изменённых jar/свои сборки (ToS), политика по CPU (overselling), реальный CPU (`/spark tps`, `cat /proc/cpuinfo`, если есть консоль).
Ограничение бесплатного тарифа — 2 ГБ: нашу сборку целиком (`-Xmx10G`) на нём не запустить, проверяются **панель, порт, SFTP, версия Forge/Java и условия**; нагрузочная проверка TPS — уже на платном тарифе (месяц).
Итог проверки → владельцу: «берём платный 16 ГБ / другой вариант» (если не прошло — понадобятся ответы на бюджет и на то, кто админит VPS).

## Вариант A: ПК друга

Сначала проверить, есть ли у друга «белый» (публичный) IP: сравнить IP в настройках роутера
(WAN) с тем, что показывает 2ip.ru. Совпадают — IP белый.

| Способ | Что ставить игрокам | Плюсы | Минусы |
|---|---|---|---|
| **Проброс порта 25565** (если IP белый) | ничего | минимальный пинг, без посредников | нужен доступ к роутеру; IP может меняться (решается DDNS) |
| **playit.gg** | ничего | работает за NAT/CGNAT, постоянный адрес, бесплатный тариф | трафик идёт через их сервер — пинг выше; на бесплатном тарифе ближайший регион может быть далеко |
| **Tailscale / ZeroTier** (виртуальная LAN) | клиент VPN у каждого | обычно прямое P2P-соединение — пинг ниже, чем у туннеля; закрыт от посторонних | каждый игрок ставит программу и входит в сеть |
| **Radmin VPN** | клиент у каждого | просто, популярен в СНГ | только Windows, иногда нестабилен |
| **e4mc** (мод) | ничего | «открыть для сети» прямо из одиночного мира | хост должен сам сидеть в игре; адрес временный — для долгой сборки не подходит |

**Рекомендация:** если IP белый — проброс порта. Если нет — **playit.gg** для простоты
(друзьям ничего ставить не нужно); если пинг через playit окажется плохим — **Tailscale**.

Требования к ПК друга для модовой сборки: 6–8 ГБ RAM под сервер (средняя сборка на 50–150 модов),
процессор с хорошей однопоточной производительностью, SSD, проводное подключение.

## Голосовой чат: UDP-порт 24454

Simple Voice Chat ходит **отдельным UDP-портом 24454** (не через порт игры 25565, который TCP).
Если игра подключается, а в голосовом чате значок «нет соединения» (перечёркнутый динамик/наушники) —
не открыт именно этот порт. Настройки сервера: `pack/config/voicechat/voicechat-server.properties`
(`port` — какой порт слушать, `voice_host` — какой адрес сообщить клиентам; пусто = тот же, что у игры).

| Способ подключения | Что сделать для голоса |
|---|---|
| **Проброс портов** (белый IP) | в роутере, кроме `25565/TCP`, пробросить **`24454/UDP`** на тот же ПК; в брандмауэре Windows разрешить входящий UDP 24454 для Java (или правилом на порт). `voice_host` не трогать. |
| **playit.gg** | Добавить в агенте **второй туннель типа UDP** на локальный `127.0.0.1:24454` (первый — Minecraft Java, TCP 25565). playit выдаст адрес вида `xxx.ply.gg:12345` или `147.185.221.x:12345` — вписать его в `voice_host=xxx.ply.gg:12345` и перезапустить сервер. Клиенты ничего не настраивают: адрес приходит от сервера. Бесплатный тариф позволяет несколько туннелей, UDP в том числе. |
| **Tailscale / ZeroTier / Radmin VPN** | Ничего: в виртуальной сети все порты, включая UDP, доступны напрямую. Друзья подключаются к адресу хоста в сети (`100.x.y.z` у Tailscale), голос идёт туда же. Брандмауэр Windows всё равно должен пропускать Java (обычно спрашивает при первом запуске — разрешить для частных сетей). |
| **e4mc** | Голос не работает: e4mc туннелирует только TCP игры. |
| **Платный хостинг** | В панели хостинга выделить дополнительный порт (часто называется «Additional port»/«Allocation») и вписать его в `port=` (и в `voice_host=адрес:порт`, если хостинг за NAT). Если хостинг даёт только один порт — `port=-1` (голос по UDP на том же номере, что игра) и обязательно `enable-query=false` в `server.properties`: query тоже слушает UDP на этом порту, и SVC предупреждает о падении сервера. Узнать у поддержки, проходит ли UDP. |

Загрузка звуков AudioPlayer через браузер (`/audioplayer web`) по умолчанию выключена — ей нужен ещё один
TCP-порт (8080). Включить: `run_web_server=true` в `config/audioplayer/audioplayer-server.properties`, порт и
внешний адрес — в `config/audioplayer/webserver.properties`; открыть порт так же, как 25565. Без неё звуки
загружаются по ссылке (`/audioplayer url`) — портов не нужно.

Проверка: зайти на сервер, нажать **V** — в окне голосового чата не должно быть надписи о недоступности
сервера; в логе сервера строка `Voice chat server started at port 24454`.

## Вариант B: платный хостинг

На что смотреть при выборе тарифа:
- **RAM**: 6–8 ГБ для средней сборки, 10–12 ГБ для тяжёлой (Create, большие тех-моды, много игроков).
- **CPU**: важна однопоточная частота (сервер Minecraft в основном однопоточный) — Ryzen 7000/9000 или
  Intel последних поколений лучше «многоядерных» Xeon старых поколений.
- **Расположение** — ближе к игрокам (пинг).
- **Доступ к файлам** (SFTP/файловый менеджер), выбор версии Java и загрузчика, автобэкапы.
- Возможность поставить свою сборку (zip / server pack), а не только из каталога хостинга.

## Офлайн-режим и защита ников

Решение владельца: часть игроков заходит с офлайн-аккаунтов (Prism → «Добавить офлайн»), поэтому сервер работает с
**`online-mode=false`**. Серверный пакет (`export-pack.sh`) кладёт `server.properties.default` с этой строкой;
`start.sh`/`start.bat` копируют его в `server.properties`, только если файла ещё нет — настройки хоста при обновлении
пакета не затираются. Если сервер у хоста уже создан — просто поставить `online-mode=false` в `server.properties`
(на платном хостинге — в панели).

## Необязательные моды (WorldEdit выключен)
Моды с `[option] optional=true, default=false` (сейчас — WorldEdit) серверный пакет и `scripts/test-server.sh` кладут не в `mods/`, а в **`mods/optional/`**
(Forge вложенные папки не читает) — сервер без них не держит ≈2,7 ГБ кучи WorldEdit и стартует на ≈2 минуты быстрее.
Включить на время переноса постройки: перенести `mods/optional/worldedit-mod-7.2.15.jar` в `mods/`, перезапустить (+2,7 ГБ памяти, первый старт дольше);
закончили — вернуть jar в `mods/optional/` и перезапустить. Команды для игроков-операторов — `docs/friends.md`, «Перенос построек».

## Сторож тиков (`max-tick-time`)
Когда включён WorldEdit (по умолчанию выключен), он на старте делает один тик дольше 60 с (перебирает состояния всех блоков сборки); по умолчанию `max-tick-time=60000`, и сторож
сервера (ServerHangWatchdog) убивает процесс примерно через минуту после `Done` — в логе «Killed», а в `crash-reports/` запись
«a single server tick took 60.00 seconds». Серверный пакет и `scripts/test-server.sh` кладут **`max-tick-time=-1`** (сторож выключен)
в новый `server.properties`; у уже созданного сервера или на платном хостинге поставить эту строку в `server.properties` (в панели) вручную.
- **Подмена ника**: в офлайн-режиме UUID выводится из ника, проверки владения ником нет — любой, знающий ник (в том
  числе оператора!), зайдёт под ним. Закрывает мод **Sol's AuthLogin** (`pack/mods/sols-authlogin`, side=server): до
  `/register` / `/login` игрок заморожен; пароли хранятся хэшем SHA-256 с солью, есть лимит попыток и временная блокировка.
  Конфиг — `config/` сервера после первого запуска. Забытый пароль сбрасывает хост через конфиг/данные мода.
  Клиентская часть мода необязательна (нужна только для токен-автовхода) — в клиентскую сборку не кладём.
- **Белый список** (дополнительно, не вместо пароля): `white-list=true` в `server.properties` и `/whitelist add <ник>`
  для каждого друга. Отсекает посторонних, но от подмены ника не защищает (ник знают все). Оператору (`/op`) в
  офлайн-режиме особенно важен пароль: оппиться он по нику.
- **Ограничения**: нет скинов с Mojang (у офлайн-игроков стандартный скин, если клиентский скин-мод не настроен);
  нет проверки владения аккаунтом; смена ника = новый игрок. **Simple Voice Chat** в офлайн-режиме работает: он
  привязывается к игроку внутренним секретом, а не сессией Mojang.
- Порт 25565 лучше не светить публично (playit/Tailscale ограничивают круг) — иначе сервер без лицензионной
  проверки открыт всем с адресом.

## Что потребуется от сборки в любом случае
`scripts/export-pack.sh` собирает оба пакета в `dist/` (инструкция для игроков — `docs/friends.md`):
- Серверный пакет `*-server.zip`: только моды со стороной `both` и `server`, конфиги, установщик Forge,
  `start.sh`/`start.bat`. Открыть порты: `25565/TCP` (игра) и `24454/UDP` (голос).
- Клиентский пакет `*.mrpack`: все моды `both` + `client`, импортируется в Prism Launcher / Modrinth App.
