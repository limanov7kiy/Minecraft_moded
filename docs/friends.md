# Как зайти на наш сервер

Нужен Minecraft Java Edition (аккаунт Microsoft **или** офлайн-аккаунт — см. ниже) и ~8 ГБ свободной оперативки на ПК.

Сборка некоммерческая, для нашей компании. В ней есть переделанные чужие моды (авторство — в `docs/`):
не продавать и не выкладывать на Modrinth/CurseForge.

## 1. Поставить сборку (один раз)
Проще всего — из файла `.mrpack` (ниже). Вариант с автообновлением через packwiz-installer — в README;
ссылка там ведёт на ветку `claude/affectionate-davinci-4gddoh` (с `main` будет 404 «Failed to download pack.toml»).

1. Скачать **Prism Launcher** — https://prismlauncher.org (или Modrinth App — https://modrinth.com/app).
2. Войти в аккаунт: *Prism → Аккаунты → Добавить Microsoft* — или, без лицензии, *Добавить офлайн* (в Prism: «Cracked»; вписать ник — латиницей, 3–16 символов, один и тот же всегда). Сервер работает в офлайн-режиме (`online-mode=false`), так что заходят оба типа аккаунтов.
3. Получить от хоста файл `Minecraft_moded-….mrpack`.
4. *Prism → Добавить экземпляр → Импорт* → выбрать `.mrpack` → OK. Лаунчер сам скачает Forge и ~230 модов.
   (Modrinth App: *Библиотека → + → Из файла*.)
5. *Экземпляр → Изменить → Настройки → Java*: память **не меньше 6144 МБ, лучше 8192** (Xmx; с 5 ГБ клиент в мире занят на 94 %). Java 17 Prism подберёт сам.
6. Запустить. Первый старт долгий (несколько минут) — это нормально.
   Ошибка **«Missing libraries»** / «библиотеки отсутствуют или ещё не скачаны» (lwjgl и т.п.) — это лаунчер не скачал
   файлы Minecraft, сборка ни при чём. Запускать обычной кнопкой *Запустить* (не «автономно»/офлайн) при рабочем
   интернете; если не помогает — включить VPN на первый запуск (из РФ бывает недоступен libraries.minecraft.net).
   Офлайн-аккаунту это не мешает: аккаунт без лицензии, а библиотеки Prism всё равно качает из сети.

macOS: модели игроков Yes Steve Model на Mac не работают, остальное — да.

## 2. Подключиться
*Сетевая игра → Добавить* → адрес, который даст хост (например `xxx.ply.gg:12345` или `100.x.y.z`).

### Первый вход: регистрация
Ник в офлайн-режиме никем не подтверждён — любой мог бы зайти под чужим ником. Поэтому на сервере стоит мод
Sol's AuthLogin (стоит только на сервере; в клиентской сборке его нет и ставить не нужно): до входа в аккаунт нельзя двигаться и
играть. При первом входе — `/register <пароль> <пароль ещё раз>`; потом при каждом входе — `/login <пароль>`
(сменить: `/change_password <старый> <новый> <новый>`). Пароль придумать свой, не от важных аккаунтов. Ник менять нельзя —
под новым ником будет новый аккаунт и новый инвентарь. Забыли пароль — написать хосту (он сбросит).

## 3. Голосовой чат
При первом входе откроется окно настройки микрофона; потом — клавиша **V**.
- **Caps Lock** (по умолчанию) — говорить (push-to-talk). В настройках можно включить активацию голосом.
- **M** — выключить микрофон, **N** — выключить голосовой чат целиком, **G** — группы
  (говорить с друзьями из группы на любом расстоянии).
- Голос слышно в радиусе ~48 блоков, сквозь стены он глуше (Sound Physics). Шёпот — отдельная клавиша в настройках.
- **Рации и радио** (мод Simple Radio): рецепты в JEI (клавиша R/U по предмету). Рации на одной частоте
  слышат друг друга далеко за пределами обычного голоса; чем дальше, тем больше помех.
- Осторожно: голос — это вибрация: скалк-сенсоры его слышат, а Хранитель идёт на звук.
- **Свои звуки** (AudioPlayer): `/audioplayer` — загрузить mp3/wav по ссылке (`/audioplayer url <ссылка>`)
  и записать на пластинку, козий рог, нотный блок или голову: взять предмет в руку →
  `/audioplayer apply <имя файла>`. Звук слышат все рядом через голосовой чат.
- **Группы**: `/instantgroup` — сразу группа со всеми рядом; `/persistentgroup add <имя>` (оператор) —
  постоянная группа; `/autojoingroup set <имя>` — заходить в неё автоматически.

Не слышно никого / значок перечёркнут — сказать хосту: у сервера не открыт UDP-порт 24454
(см. `docs/hosting.md`).

### Если русский перевод не включился
Русификация подключается модом `ru-lang` (всегда включённый ресурспак «Русификация сборки», выше остальных паков), поэтому обычно делать ничего не нужно.
Если у вас старая сборка без этого мода и часть текста английская/китайская: Настройки → Язык → Русский, затем Настройки → Пакеты ресурсов →
переведите `russian-moded.zip` в активные и поставьте **самым верхним** (после установки мода автовключения это не требуется).

## Обновление сборки
Хост присылает новый `.mrpack` → импортировать как новый экземпляр, старый удалить. Миры на сервере;
свои настройки (клавиши, звук, голосовой чат) можно перенести, скопировав `options.txt` и папку
`config/voicechat/` из старого экземпляра.

---
## Хосту: как сделать пакеты и запустить сервер
1. `PACKWIZ=~/go/bin/packwiz scripts/export-pack.sh` → в `dist/` появятся `*.mrpack` (раздать друзьям) и
   `*-server.zip`.
2. Распаковать `*-server.zip` на машину сервера (нужна Java 17), запустить `start.bat` (Windows) или
   `./start.sh`. Первый запуск ставит Forge и просит принять EULA: создать `eula.txt` со строкой `eula=true`.
3. ОЗУ сервера — `user_jvm_args.txt` (по умолчанию 10 ГБ). Открыть порты **25565/TCP** и **24454/UDP**
   (или туннели playit.gg / Tailscale) — подробно в `docs/hosting.md`.
