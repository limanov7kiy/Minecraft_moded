# Как зайти на наш сервер

Нужен лицензионный Minecraft Java Edition и ~8 ГБ свободной оперативки на ПК.

Сборка и файлы из неё — только для нашей компании: никуда не выкладывать и не пересылать посторонним
(в ней есть переделанные чужие моды, их нельзя распространять публично).

## 1. Поставить сборку (один раз)
1. Скачать **Prism Launcher** — https://prismlauncher.org (или Modrinth App — https://modrinth.com/app).
2. Войти в аккаунт Microsoft: *Prism → Аккаунты → Добавить Microsoft*.
3. Получить от хоста файл `Minecraft_moded-….mrpack`.
4. *Prism → Добавить экземпляр → Импорт* → выбрать `.mrpack` → OK. Лаунчер сам скачает Forge и ~140 модов.
   (Modrinth App: *Библиотека → + → Из файла*.)
5. *Экземпляр → Изменить → Настройки → Java*: память **6144–8192 МБ** (Xmx). Java 17 Prism подберёт сам.
6. Запустить. Первый старт долгий (несколько минут) — это нормально.

macOS: модели игроков Yes Steve Model на Mac не работают, остальное — да.

## 2. Подключиться
*Сетевая игра → Добавить* → адрес, который даст хост (например `xxx.ply.gg:12345` или `100.x.y.z`).

## 3. Голосовой чат
При первом входе откроется окно настройки микрофона; потом — клавиша **V**.
- **Caps Lock** (по умолчанию) — говорить (push-to-talk). В настройках можно включить активацию голосом.
- **M** — выключить микрофон, **N** — выключить голосовой чат целиком, **G** — группы
  (говорить с друзьями из группы на любом расстоянии).
- Голос слышно в радиусе ~48 блоков, сквозь стены он глуше (Sound Physics). Шёпот — отдельная клавиша в настройках.
- **Рации и радио** (мод Simple Radio): рецепты в JEI (клавиша R/U по предмету). Рации на одной частоте
  слышат друг друга далеко за пределами обычного голоса; чем дальше, тем больше помех.
- Осторожно: голос — это вибрация: скалк-сенсоры его слышат, а Хранитель идёт на звук.
- **Свои звуки** (AudioPlayer): `/audioplayer` — загрузить mp3/wav по ссылке (`/audioplayer url <ссылка>`)
  и записать на пластинку, козий рог, нотный блок или голову: взять предмет в руку →
  `/audioplayer apply <имя файла>`. Звук слышат все рядом через голосовой чат.
- **Группы**: `/instantgroup` — сразу группа со всеми рядом; `/persistentgroup add <имя>` (оператор) —
  постоянная группа; `/autojoingroup set <имя>` — заходить в неё автоматически.

Не слышно никого / значок перечёркнут — сказать хосту: у сервера не открыт UDP-порт 24454
(см. `docs/hosting.md`).

## Обновление сборки
Хост присылает новый `.mrpack` → импортировать как новый экземпляр, старый удалить. Миры на сервере;
свои настройки (клавиши, звук, голосовой чат) можно перенести, скопировав `options.txt` и папку
`config/voicechat/` из старого экземпляра.

## Хосту: как сделать пакеты и запустить сервер
1. `PACKWIZ=~/go/bin/packwiz scripts/export-pack.sh` → в `dist/` появятся `*.mrpack` (раздать друзьям) и
   `*-server.zip`.
2. Распаковать `*-server.zip` на машину сервера (нужна Java 17), запустить `start.bat` (Windows) или
   `./start.sh`. Первый запуск ставит Forge и просит принять EULA: создать `eula.txt` со строкой `eula=true`.
3. ОЗУ сервера — `user_jvm_args.txt` (по умолчанию 10 ГБ). Открыть порты **25565/TCP** и **24454/UDP**
   (или туннели playit.gg / Tailscale) — подробно в `docs/hosting.md`.
