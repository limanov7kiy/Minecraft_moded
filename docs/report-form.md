# Форма отчётов от игроков и роль приёмщика

Репозиторий публичный, поэтому **отчёты, логи, скриншоты и ссылки spark в git, в публичных Issues и на публичных страницах не хранятся**.
Приём — в приватной Google Форме владельца. Ссылку на форму получают только друзья (в репозиторий не вписывается).

## Как создать форму (владельцу, ~10 минут)
Две формы вместо одной: для файлов Google требует вход в аккаунт, и это лишний барьер для простого «не работает».

### Форма А — «Быстрый отчёт» (без входа в Google, без файлов)
Настройки: *Ответы → Таблица Google; «Собирать адреса эл. почты» — выкл.; «Ограничить одним ответом» — выкл.; ответы видит только владелец.*

| Поле | Тип | Обязательно | Подсказка для игрока |
|---|---|---|---|
| Псевдоним | Короткий текст | да | `Player-xxxx` из конца вывода скрипта диагностики. Не знаете — придумайте любой, НЕ ваш ник в игре |
| Версия сборки | Короткий текст | да | Дата последнего обновления сборки (или номер из Prism). Если не знаете — «не знаю» |
| Пункт «Что нового» | Выпадающий список | нет | W1–W10 из `docs/whats-new-check.md` или «другое» |
| Где играли | Выбор | да | Одиночная игра / сервер друзей |
| Мод или предмет | Короткий текст | нет | Если знаете (подсказка Jade при наведении, вкладка Mods). Не знаете — «не знаю» |
| Что не работает | Абзац | да | Что вы делали, что ожидали и что получилось |
| Шаги | Абзац | нет | 1–2–3: как повторить. Не повторяется — так и напишите |
| Как часто | Выбор | нет | Один раз / иногда / каждый раз |
| Ссылка spark | Короткий текст (ссылка) | нет | Если лагает: в мире `/spark profiler start`, 2–3 минуты игры, `/spark profiler stop`, ссылку из чата сюда |
| Ссылка на файлы | Короткий текст | нет | Если логи слишком большие: ссылка на облако с доступом по ссылке (срок — неделя) |
| ОС / видеокарта / память для игры | Короткий текст | нет | Например: Windows 11, RTX 2060, 8192 МБ |

Предупреждение вверху формы: *«Не вставляйте пароли, IP сервера, адрес дома и реальное имя. Логи сюда не вставляйте — для них вторая форма.»*

### Форма Б — «Отчёт с логами» (нужен вход в Google, файлы на Диск владельца)
Те же поля + *вопрос «Загрузка файлов»*: типы — «Архив», «Изображение», «Документ»; до 5 файлов; до 1 ГБ на файл.
Подсказка: *«Лучше всего — `diag-Player-xxxx-….zip` от скрипта диагностики (ник и IP в нём заменены). Скриншоты: F2, папка `minecraft/screenshots`.»*
Файлы лежат на Диске владельца в папке формы: **не включать общий доступ и «доступ по ссылке» к этой папке**.

### Запасной путь
Нет Google-аккаунта — отправить zip лично владельцу (личное сообщение). Ссылка/файл не публикуются.

## Что просим прислать (кратко)
1. `diag-Player-….zip` от `scripts/collect-diagnostics.bat` (маскировка ника/IP внутри; см. `docs/diagnostics.md`).
2. Для вылета — `crash-reports/crash-….txt`; игра закрылась молча — `hs_err_pid….log`. Если не сделали zip, перед отправкой замените
   ник и IP в текстовых файлах вручную (поиск и замена).
3. Скриншот (F2) и название предмета/моба.
4. Ссылка spark при лагах.

## Роль «приёмщика»
Приёмщик — сеанс/помощник, которому владелец даёт доступ к таблице ответов и папке с файлами. Он **не** публикует и не коммитит чужие данные.

**Задачи**
1. Раз в день (или по просьбе) забрать новые ответы из таблицы.
2. Скачать файлы только во временную папку вне репозитория (`mktemp -d`), читать скриптами Python с `-I`, файлы не запускать и не открывать
   в IDE репозитория. После анализа папку **удалить** (`rm -rf`).
3. Классифицировать: версия сборки → мод (по стеку краша, `mods.csv`, пункту W<n>) → тип (вылет / фриз / визуально / логика / вход на сервер).
4. Проверить дубли: тот же мод и симптом у других игроков = один кластер. Сверить с `docs/compat.md` и `docs/whats-new-check.md`:
   известное — ссылка на пункт; новое — кандидат в `compat.md` (**без** ников, IP, путей, кусков чатов).
5. Сводка владельцу (в чат, не в git): таблица «кластер — сколько игроков — версия — мод — вероятная причина — что снять дополнительно»,
   отдельно «критично» (вылеты, потеря мира, безопасность).
6. Правила хранения: не пересылать логи другим сеансам целиком — только выжимку (строки ошибки, имя мода, версия); при подозрении на
   личные данные в ответе (пароль, адрес) — сообщить владельцу, чтобы он удалил строку в таблице.
7. В публичные файлы (`docs/compat.md`, `docs/whats-new-check.md`) попадают только обобщённые выводы: «у N игроков при X происходит Y, мод Z».

**Формат выжимки для потоков-исправителей** (можно в PR): версия сборки, мод и его версия, симптом, шаги, 3–10 строк лога с замаскированными
данными, «сколько игроков».
