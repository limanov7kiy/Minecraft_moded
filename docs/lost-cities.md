# Заброшенные города (The Lost Cities)

Запрос владельца: «Добавь в сборку модификацию, чтобы была генерация случайных заброшенных городов»; решение: **«города в обычном мире»**
(основное измерение Overworld, не отдельное). Сделано 2026-10-12 (поток 6).

## Выбор мода

| Кандидат (1.20.1 Forge) | Что это | Вердикт |
|---|---|---|
| **The Lost Cities** 1.20-7.5.7 (McJty, MIT, обновлён 2026-10-04, 11 млн загрузок) | Города, дороги, шоссе, метро, подвалы с лутом и спавнерами **внутри обычного ландшафта Overworld**; профиль задаёт частоту/высоту/разрушения; работает только на сервере; политика: «Feel free to use Lost Cities in any modpack» | **Выбран.** Единственный полноценный; в обычном мире, как просил владелец |
| The Lost City by Berezka 1.4.1 | Небольшие заброшенные поселения | Нет: All Rights Reserved, мало, не города |
| LC2H (Lost Cities: Multithreaded) | Многопоточность для старого Lost Cities | Не нужен: в Lost Cities 7.5.x генерация уже потокобезопасна/многопоточная (changelog 7.5.0–7.5.6) |
| Lost Souls, ChaosZPack [Lost Cities], Lost Cities Modern Tweaks | Аддоны/датапак к Lost Cities (мобы, здания, правки) | Не добавлены: по желанию позже (все требуют Lost Cities, MIT/свободные) |
| Grim Kingdoms, Little Structures, Abandoned* | Замки/руины/дома, не города | Не подходят под «города» |

## Как включается (важно)
На 1.20.1 Lost Cities — не тип мира. Профиль читается из серверного конфига **при создании мира**: `pack/defaultconfigs/lostcities-server.toml`
(Forge копирует `defaultconfigs/` в `<мир>/serverconfig/` новому миру; `scripts/test-server.sh` и `scripts/export-pack.sh` теперь кладут `defaultconfigs/`
на сервер, packwiz — игрокам для их одиночных миров). **Ключи должны лежать в таблице `[profiles]`** — на верхнем уровне Forge их «исправляет» на пустое
значение, и города не появляются (так было при первой проверке).
```toml
[profiles]
	selectedProfile = "rarecities"
	selectedCustomJson = ""
```
На **уже созданном** мире профиль не меняют: новые чанки дадут резкую границу. Для включения — новый мир (или другой `level-name`).
Мод поставлен как `both` (на сервере обязателен; клиенту нужен для экрана настройки профиля в одиночной игре).

## Частота: профиль (развилка, рекомендован `rarecities`)
Замер `scripts/tests/lostcities.js` (сетка ±1500 блоков вокруг спавна, seed 12345, наш полный набор модов):

| Профиль | «Городских» чанков | Комментарий |
|---|---:|---|
| `default` (cityChance 0,01) | **37 %** | города и шоссе почти везде; много для мира с десятками структурных модов |
| **`rarecities`** (cityChance 0,001, без руин) | **5,8 %** | редкие города среди обычных биомов — **выбран владельцем (В10, «а»)**, действует для нового мира |

Другие профили Lost Cities: `nodamage` (без разрушений), `safe`, `ancient`, `wasteland`, `tallbuildings` (очень высокие, тяжело), `largecities`,
`onlycities` (весь мир — город), `cavern`/`floating`/`space`/`biosphere`/`atlantis` (иные ландшафты; не для нашей сборки). Смена — строка
`selectedProfile`; тонкая настройка частоты — `selectedCustomJson` (пример: в одиночной игре настроить в экране мира и скопировать результат).

## Проверки
- `scripts/test-server.sh` в новом мире: **`Done` за 123 с** (Lost Cities ошибок в логе не даёт), профиль `rarecities` применился
  (`world/serverconfig/lostcities-server.toml`), тест `scripts/tests/lostcities.js`: 36 из 625 выборок — городские чанки, 12 из них сгенерированы
  (в зданиях стекло, бетон, кирпич, асфальт — ≈ 1200 блоков в выборке), `LCCHECK OK`.
- Нагрузка: генерация городского чанка из скрипта в главном потоке ≈ 2,8 с (холодный старт, облачная ВМ) — на ноутбуке владельца (i5-9, RTX 2060,
  16 ГБ) реальную нагрузку смотреть в игре: `/spark profiler`; если тяжело — `rarecities` уже минимальный, не включать `tallbuildings`/`largecities`.
- Совместимость: структуры ванили (`mansion`, `pyramid`, `igloo`, `swamp_hut`, `outpost`) Lost Cities обходит сам (`avoidStructures`); для наших
  структурных модов (Cataclysm и др.) список можно дополнить в `defaultconfigs` — не требовалось. Измерения Ad Astra/Northstar/Aether/Twilight Lost Cities не трогает
  (только Overworld; своё измерение `lostcities:lostcity` — биосфера, в нём ничего не появляется без портала).
- Русификация: у мода один ключ (`generator.lc_cavern`) — переведён в `russian-moded`. Экран настройки профиля — захардкожен английским.
