# HBM's Nuclear Tech Mod (NTM): решение и сверка со сборкой

**Решение владельца 2026-10-26: не добавляем; пересмотреть, если появится стабильный порт с реакторами.**
Дословно: «альфа порты нам не нужны, если функционал присутствует, добавлять не будем».
NTM в сборку **не добавляем**. Под 1.20.1 Forge у него есть только alpha-порты (список ниже), а основной
функционал NTM в сборке уже есть.

## Функционал NTM → что уже есть у нас

| Функция NTM | Что есть в сборке (`pack/modlist.txt`) |
|---|---|
| Реакторы деления (RBMK, PWR, ZIRNOX) | Mekanism Generators: реактор деления (мультиблок, перегрев, авария с выбросом радиации) |
| Термояд (Fusion, ICF) | Mekanism Generators: термоядерный реактор |
| Турбины, охлаждение | Mekanism Generators: индустриальная турбина; Create (пар, двигатели) |
| Энергосеть, аккумуляторы | Mekanism (кабели, индукционная матрица), Create Crafts & Additions |
| Переработка урана и топлива (центрифуга, обогащение, отходы, плутоний, полоний) | Mekanism: жёлтый кек → гексафторид урана → делящееся топливо, ядерные отходы → плутоний/полоний, антиматерия; уран Alex's Caves |
| Радиация и заражение | Mekanism (радиация в мире и у игрока, дозиметр, счётчик Гейгера); облучение Alex's Caves |
| Защитные костюмы | Mekanism: химзащитный костюм (hazmat); броня Alex's Caves от облучения |
| Ядерные бомбы | Alex's Caves: ядерная бомба (Токсичные пещеры); CBC Nukes (`cbc_nukes-2.1.1-mmport.jar`): ядерные снаряды Create Big Cannons |
| Ракеты, огнестрел | Superb Warfare (огнестрел, ракеты, техника) |
| Осадки, кратеры, «мёртвые» биомы, Sellafield | нет — не добавляем |
| Особые бомбы NTM (FLEIJA, Balefire, антиматерия) | нет — не добавляем |

Ключевой функции NTM, которой у нас нет совсем и под которую был бы нужен отдельный мод, не нашлось.

## Рассмотренные варианты (итог — «г»)

- а) полный NTM (alpha-порт Masala37) — **отклонён**: сырой порт, в основном бомбы, риск для общего мира;
- б) только энергетика NTM — **на будущее**: в портах пока нет рабочих реакторов;
- в) аналог Create Nuclear — **добавлен 2026-10-26** по решению владельца («если сильно не нагрузит сборку, то добавляй»), сборка 2026.10.26-1, PR #167;
  замеры и настройки — `docs/compat.md` «Create Nuclear»;
- г) не добавлять — **принят**.

## Изученные порты (на будущее, 2026-10-26)

Все порты — alpha, у всех пометка «делайте бэкап мира», survival не готов. Если владелец когда-нибудь пересмотрит
решение, смотреть первым Masala37: реакторы появятся, когда в нём доделают RBMK.

- [Hbm's Nuclear Tech: 1.20.1 Port](https://modrinth.com/mod/hbms-nuclear-tech-1.20.1-port) — Masala37, GPL/LGPL-3,
  1.0.33-alpha (2026-09-14), 50 МБ. Бомбы, радиация, ракеты, часть машин. RBMK — только каркас, PWR — только
  корпуса, оружия нет. Общего запрета на разрушение блоков взрывами в конфиге нет, только радиусы.
- [HBM's Nuclear Tech Modernized](https://modrinth.com/mod/hbms-nuclear-tech-modernized) — Raptor324, GPL-3,
  0.2.1-alpha (2026-08-09). Переписан с нуля, контента мало, реакторов нет.
- [HBM-NTM-high-edition](https://modrinth.com/mod/hbm-ntm-high-edition) — Nteum, LGPL-3, 0.4.10-beta (2025-11).
  Взрывы есть, радиации нет.
- [Muddy Edition](https://modrinth.com/mod/hbm-ntm-me) — GPL-3, 2.0.0-alpha (2025-11). Почти пусто.
- [Jackasm/HBM-1.20.1](https://github.com/Jackasm/HBM-1.20.1) — закрытый тест, релизов нет.
- [NTM Remake](https://github.com/MartinTheDragon/Nuclear-Tech-Mod-Remake) — только 1.18.2, заброшен.
